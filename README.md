# בית ספר חכם

לוח משפחתי של שיעורי בית, משימות, ציונים והתראות

מושך שיעורי בית ומשימות מ**סמארטסקול** ומ**אופק** בשביל כל ילד, דרך הזדהות משרד החינוך, ומציג את הכול בלוח אחד.

## הפעלה
לחיצה כפולה על `start.bat`. הדפדפן ייפתח בכתובת http://127.0.0.1:8765

1. בעמוד **הגדרות** מוסיפים כל משתמש עם קוד המשתמש והסיסמה שלו במשרד החינוך.
2. לוחצים **סנכרון**.
3. אם ההזדהות מבקשת קוד SMS או אימות, לוחצים **התחברות ידנית**. נפתח חלון דפדפן גלוי, הפרטים כבר ממולאים, ומשלימים את ההתחברות. ההתחברות נשמרת לסנכרונים הבאים.

## איך זה עובד
- לכל ילד יש פרופיל דפדפן נפרד (`data/profiles/child-N`), כך שההתחברויות של הילדים לא מתערבבות.
- הסיסמאות נשמרות ב־Windows Credential Manager ולא בקבצים.
- **סמארטסקול:** כרטיס תלמיד, מודול "שיעורים ושיעורי בית" (`PupilCard/GetPupilLessonsAndHomework`), לשבוע שעבר, לשבוע הנוכחי ולשבוע הבא.
- **אופק:** המשימות מלוח התלמיד (`dashboardapi.students.getTasks`), חודשיים אחורה וחצי שנה קדימה.
- אם הסיסמה נדחתה, הכלי מפסיק לנסות אותה אוטומטית, כדי שהחשבון לא יינעל.
- הנתונים הגולמיים של כל סנכרון נשמרים ב־`data/raw` ומוצגים בעמוד "יומן סנכרון", לצורך אבחון.
