# בית ספר חכם

לוח משפחתי שמרכז שיעורי בית, משימות, ציונים והתראות של כל הילדים מ**סמארטסקול (Webtop)**, **אופק** ו**גלים פרו**, ומציג אותם במקום אחד. רץ על מחשב Windows או על שרת Linux, ונפתח בדפדפן בכתובת מקומית.

## הפעלה
**Windows:** לחיצה כפולה על `start.bat`. **Linux:** `./start.sh` (פרטים בהמשך). בפעם הראשונה הוא מתקין את הסביבה ואת הדפדפן. אחר כך הלוח נפתח בכתובת http://127.0.0.1:8765

1. בעמוד **הגדרות** מוסיפים משתמשים. לכל משתמש בוחרים שיטת כניסה:
   - **הזדהות משרד החינוך**: לתלמידים. מתאים לסמארטסקול, אופק וגלים פרו.
   - **משתמש וסיסמה של וובטופ**: לחשבון הורה בסמארטסקול. מביא את כל הילדים המקושרים אליו, גם מכמה בתי ספר.
   - **ללא כניסה**: ילד שהנתונים שלו מגיעים מחשבון ההורה. ילד כזה נוצר אוטומטית, אם מופיע בחשבון ההורה ילד שאין לו משתמש.
2. לוחצים **סנכרון**.
3. אם האתר דורש קוד SMS או "אני לא רובוט", לוחצים **התחברות ידנית**. נפתח חלון דפדפן גלוי עם הפרטים ממולאים, ומשלימים את ההתחברות בעצמכם. ההתחברות נשמרת לסנכרונים הבאים.
4. כדי לסנכרן כל יום: ב**הגדרות**, בכרטיס **סנכרון אוטומטי**, מסמנים "לסנכרן כל יום בשעה קבועה" ושומרים. ב־Windows נוצרת משימה במתזמן המשימות, וב־Linux נוספת שורה ל־crontab. הסנכרון רץ גם כשהכלי סגור.

## העמודים
- **סיכום**: מספרים מרכזיים, כרטיס לכל ילד, עומס הגשות ל־14 יום, ציונים אחרונים, התראות לפי סוג ועדכונים אחרונים.
- **משימות**: מחולקות לפי מועד הגשה. שיעורי בית ישנים (מעל 3 שבועות) מופיעים בחלק מקופל.
- **ציונים** ו**התראות**: עם סינון לפי ילד וסוג.
- תגית "חדש" על כל פריט שעוד לא הוצג, ומספר ליד כל עמוד בסרגל העליון.
- **יומן סנכרון**: תוצאות כל סנכרון, והתשובות הגולמיות מהאתרים לצורך אבחון.

## פרטיות ואבטחה
- הסיסמאות נשמרות במנהל הסיסמאות של מערכת ההפעלה (ב־Windows: Credential Manager). בשרת Linux בלי מנהל סיסמאות הן נשמרות ב־`data/credentials.json`, שרק המשתמש שמריץ את הכלי יכול לקרוא (הרשאות 600). הן אף פעם לא נכנסות למאגר.
- כל הנתונים (`data/`: מסד הנתונים, פרופילי הדפדפן לכל משתמש, התשובות הגולמיות מהאתרים) נשארים על המחשב, ולא נכללים במאגר (`.gitignore`).
- השרת מאזין רק ל־`127.0.0.1`, כלומר הלוח נגיש רק מאותו מחשב.
- הכלי לא עוקף בדיקות "אני לא רובוט" או קודי SMS. כשהם נדרשים, ההתחברות נעשית ידנית.
- אם סיסמה נדחתה, הכלי מפסיק לנסות אותה אוטומטית, כדי שהחשבון לא יינעל.

## איך זה עובד
- לכל משתמש יש פרופיל דפדפן נפרד (`data/profiles/child-N`), כך שההתחברויות לא מתערבבות. אחרי ההתחברות הכלי בודק שהאתר מחובר בשם המשתמש הנכון.
- **סמארטסקול:** כרטיס התלמיד: שיעורים ושיעורי בית (`PupilCard/GetPupilLessonsAndHomework`) וציונים (`PupilCard/GetPupilGrades`). בנוסף התראות (`Notification/GetNotificationList`). בחשבון הורה המעבר בין בתי ספר נעשה דרך `user/ChangeUser`.
- **אופק:** המשימות מלוח התלמיד (`dashboardapi.students.getTasks`).
- **גלים פרו:** פרטי המשתמש מ־`userdata.galim.org.il`, והמשימות מ־`lms.galim.org.il/personal_api/tasks`.

## Linux (שרת)
```bash
git clone <repo-url> ~/kids-homework && cd ~/kids-homework
./start.sh                      # בפעם הראשונה: יוצר סביבה ומוריד את Chromium
sudo .venv/bin/python -m playwright install-deps chromium   # פעם אחת, אם הדפדפן לא עולה
sudo apt install fonts-noto-core                            # גופנים בעברית לחלון ההתחברות הידנית
```
- **גישה מהמחשב שלך:** הכלי מאזין רק ל־`127.0.0.1` של השרת. הדרך הבטוחה היא מנהרת SSH: `ssh -L 8765:127.0.0.1:8765 user@server`, ואז פותחים http://127.0.0.1:8765 במחשב שלך. אפשר להאזין לרשת עם `HOST=0.0.0.0 ./start.sh`, אבל אין בלוח סיסמת כניסה, ולכן לא מומלץ.
- **התחברות ידנית בלי מסך:** בשרת אין חלון דפדפן, ולכן הכפתור "התחברות ידנית" פותח בלוח את עמוד **התחברות ידנית**. בעמוד רואים את הדפדפן של השרת כתמונה חיה, לוחצים עליה (למשל על "אני לא רובוט") ומקלידים (למשל קוד SMS).
- **שירות קבוע:** `deploy/smart-school.service` הוא שירות systemd למשתמש. ההוראות בראש הקובץ.
- **סנכרון יומי:** דרך cron. אם השרת כבוי בשעה שנקבעה, הסנכרון של אותו יום מדולג.
- **מעבר ממחשב אחר:** פרופילי הדפדפן והסיסמאות לא עוברים בין מערכות. בשרת מזינים סיסמאות מחדש ב"הגדרות" ומתחברים מחדש.

## דרישות
Windows או Linux, ו־Python 3.12 ומעלה. שאר התלויות מותקנות אוטומטית מ־`requirements.txt`.
